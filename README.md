# AuraGo 炁体围棋

> 让气可视化，让决策更清晰

AuraGo（炁体围棋）是一款创新的围棋游戏，通过可视化"气"的概念，帮助玩家更直观地理解围棋策略，提升棋力。

## ✨ 核心特色

### 气的可视化系统

传统围棋中，"气"是一个抽象概念，需要玩家自行计算。AuraGo 通过以下方式让气变得可见：

- **气的归属**：用黑白灰涂色清晰标识每个空点的气属于哪方
- **气数显示**：每颗棋子上直接显示该棋块的气数
- **领地范围**：淡色背景标识被一方完全包围的区域
- **眼位标记**：圆圈+点标记真眼位置

### 智能预测系统

- **落子预测**：悬停时实时显示落子后的气数变化
- **势力范围**：用虚线框显示落子后控制的气格
- **禁着点提示**：悬停在禁着点时显示原因（劫争/自杀）

### 游戏辅助功能

- **叫吃警告**：棋块只剩1气时显示警告
- **劫争标记**：劫争位置显示橙色循环箭头
- **音效反馈**：落子、提子、叫吃都有对应音效
- **最后落子标记**：红色小圆点标记最后一手

## 🎮 功能特性

### 游戏模式

#### 人人对弈
- 两位玩家在同一设备上对弈
- 适合面对面交流、教学

#### 人机对弈
- **模块化 AI 设计**：AI 模块独立，后续可替换为更强的算法
- **三档难度**：
  - 简单：随机落子，偶尔提子（适合初学者）
  - 中等：优先提子、连接，偶尔进攻（有一定策略性）
  - 困难：完整策略（提子、防守、叫吃、连接、占据要点）
- **玩家选择**：可选择执黑或执白

### 可视化模式（可独立开关）

1. **数字显示**：棋子上显示气数
2. **气的归属**：棋子周围的半透明区域
3. **领地范围**：淡色背景标记被包围区域
4. **眼位标记**：圆圈+点标记真眼

### 游戏操作

- 停一手（Pass）
- 悔棋（人机模式下会同时悔掉 AI 的棋）
- 重新开始

### 交互提示

- 鼠标悬停棋块：显示详细信息（棋子数、气数、状态）
- 鼠标悬停空位：显示落子预测（气数变化、势力范围）
- 鼠标悬停禁着点：显示禁着原因

## 📖 使用说明

### 基本操作

1. **选择游戏模式**：右侧面板选择"人人对弈"或"人机对弈"
2. **人机模式设置**：选择玩家执黑/白，选择 AI 难度
3. **落子**：点击棋盘空位
4. **查看信息**：鼠标悬停在棋子或空位上
5. **切换模式**：右侧控制面板开关可视化功能
6. **游戏控制**：使用停一手、悔棋、重新开始按钮

### 颜色说明

- **黑色半透明区域**：黑棋的气
- **白色半透明区域**：白棋的气（带黑色边框）
- **灰色半透明区域**：公气（双方共享）
- **绿色数字**：预测气数（悬停时显示）
- **红色脉冲**：叫吃警告

### 图标说明

- 🔴 红色小圆点：最后落子位置
- 🔄 橙色循环箭头：劫争位置
- ⭕ 圆圈+点：真眼位置
- ❌ 红色叉号：禁着点

## 🎯 围棋规则简介

围棋是一种策略性两人棋类游戏，规则简洁但变化无穷：

### 基本规则

1. **对弈双方**：黑方先行，交替落子
2. **落子规则**：棋子落在交叉点上，落子后不可移动
3. **气的概念**：棋子周围相邻的空点称为"气"
4. **提子规则**：当一方棋子的气被完全占据，该方棋子被提走
5. **禁着规则**：不能自杀（落子后自己无气且不能提对方子）
6. **劫争规则**：不能立即回提（需要先在别处落子）

### 胜负判定

- 双方连续停手，游戏结束
- 计算领地（被完全包围的空点）
- 领地多的一方获胜
